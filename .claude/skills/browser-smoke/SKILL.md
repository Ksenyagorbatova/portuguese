# Браузерный смоук тренажёра

## Зачем

CLAUDE.md (шаг 7 рабочего процесса) требует помимо автотестов **вручную проверить
затронутую функциональность И смежную, которую правка могла задеть**. Этот скилл —
что именно прокликать и как войти. Подсистема UI — baseline-спека
[`training-ui-and-shell.md`](../../../specs/feature/training-ui-and-shell.md).

## Запуск

- `npm run dev` → http://localhost:5173/ (в worktree порт **смещён** — бери из вывода
  Vite; см. [CLAUDE.md → Worktree](../../../CLAUDE.md)).
- Нужен живой бэкенд: `npx convex dev` в отдельном терминале (без него — экран
  загрузки, офлайна нет).
- Верифицируй сам через инструменты предпросмотра (`preview_start`, `preview_snapshot`,
  `preview_click`, `preview_screenshot`, `preview_console_logs`) — **не проси
  пользователя проверять вручную**, покажи доказательство (скриншот/консоль).

## Вход (регистрация ВРЕМЕННО ЗАКРЫТА флагом)

Флоу регистрации готов, но публичный sign-up закрыт: `SIGNUP_ENABLED = false` в
[`convex/auth.ts`](../../../convex/auth.ts) + [`SignIn.tsx`](../../../src/components/SignIn.tsx)
(решение владельца 2026-09-26: репозиторий и сайт публичные; откроется перед App Store).
Переключатель «Нет аккаунта?» на экране входа скрыт, сервер отвечает
`REGISTRATION_DISABLED` на любой signUp.

- **Worktree:** готовый `dev@example.com` / `12345678q` (сеется `npm run wt:setup` /
  пере-сид `npm run wt:seed`) — основной способ входа.
- **Основной checkout:** облачный dev-деплой — свои креды (см. память про
  dev-окружение) или уже заведённые smoke-аккаунты.
- **Проверить сам флоу регистрации** (на dev/локальном, никогда на проде): открыть
  серверный гейт `npx convex env set SIGNUP_ENABLED true` (снять — `env remove`),
  а UI-переключатель в CT/сторибуке — пропом `signupEnabled` у `SignIn`; на живом
  сайте кнопки регистрации при закрытом клиентском флаге нет.
- Смоук экрана входа при ОТКРЫТОМ гейте: переключатель «Нет аккаунта?» ↔ «Уже есть аккаунт?» меняет
  форму (переключатель — `<button>`, достижим Tab'ом, кольцо фокуса); регистрация
  сразу впускает на дашборд; повторная регистрация того же email (в любом регистре)
  показывает «Аккаунт с таким email уже есть — войдите.» и НЕ впускает даже с верным
  паролем; неверный пароль при входе — «Не удалось войти. Проверьте email и пароль.».
- **iOS-приложение** (Capacitor): смоук — в iOS-симуляторе, не в браузере; матрица и
  протокол — [`specs/feat/ios-capacitor-app.md`](../../../specs/feat/ios-capacitor-app.md)
  и раннбук рядом.

## Карта экранов

`App` разводит: `AuthLoading → Splash`, `Unauthenticated → SignIn`,
`Authenticated → Shell`. **Хедер:** слева логотип-кнопка «на главный» (фон — флаг
Португалии), справа — стрик 🔥 и звук. Тема, автоозвучка и аккаунт — в профиле.
`Shell` — оркестратор: нижние разделы «Сегодня»/«Курс»/«Профиль»; во время сессии
только выход, позиция задания и звук, учебные действия закреплены снизу.

## Потоки смоука (пройти затронутые + смежные)

1. **Вход → дашборд.** Нижние разделы «Сегодня»/«Курс»/«Профиль»; статистика
   занятия видна только на его финале, а не над последующими экранами.
2. **Темы → урок.** Первый заход — онбординг-теория; кнопка теории доступна и потом
   (теория **не скрывается** после прохождения). Страницы максимум по четыре слова,
   «Следующие слова» / «Предыдущие слова», на последней — «Начать практику».
3. **Сессия.** Первое слово — всегда **MC** (выбор); дальше микс MC/Type; строка
   прогресса = **позиция** `idx+1/N` (знаменатель статичен, это не % освоения);
   Feedback («Дальше») → `Complete`. На телефоне нижняя кнопка доступна при
   клавиатуре и переносе плиток; длинный разбор докручивается над ней.
4. **Кросс-предложение** (`SentenceBuilder`) — всплывает при освоении темы (≥80% +
   выученные `required`); на сервер прогресс не пишет.
5. **Повторение** (`ReviewTab`) — кольцо «% выучено», плитки просмотрено/выучено/
   к повтору, баннер действия, `due`-слова.
6. **Стрик** 🔥 растёт на первом ответе за календарный день.
7. **Тема в профиле** — light / dark / **system**: переключить, проверить, что нет вспышки при
   загрузке (anti-flash в [`index.html`](../../../index.html); спека
   [`theme-system-mode.md`](../../../specs/feature/theme-system-mode.md)).
8. **Озвучка** — тап по flip-карточке теории / слову → произношение европейским
   pt-PT (Web Speech API).

## Что считать «смежным»

- Правка **SRS/планировщика** → проверь и сессию, и классификацию на дашборде
  (`new`/`due`/`learned`/`ongoing`), и подпись «следующий повтор».
- Правка **контента** → новую тему/урок И вкладку «Повторение» (слова подхватились).
- Правка **темы/CSS** → светлую, тёмную И системную; хедер; сессию до ~640px высоты.
- Правка **авторизации** → вход, выход, регистрация нового email (и повторная —
  дружелюбная ошибка), переключатель формы.
