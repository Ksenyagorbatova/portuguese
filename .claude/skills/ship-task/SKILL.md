# Ship task — довести задачу до PR через все гейты

Оркестрирует финальную последовательность из [CLAUDE.md → Рабочий
процесс](../../../CLAUDE.md). Каждый гейт зелёный, иначе — **стоп и чини**, не
переходи к следующему. Вызов скилла означает, что пользователь санкционировал
коммит/push/PR этой ветки (обычное правило репо — «коммит только по просьбе»).

## Предусловие

Ты на **feature-ветке** (`feat/…`/`fix/…`/`chore/…`), ответвлённой от свежего
`origin/main`. Если на `main` или detached — **стоп**: перенеси работу на ветку
(CLAUDE.md правило 1). Сверь `git status` / `git rev-parse --abbrev-ref HEAD`.

## Гейты по порядку

1. **Тесты на месте.** Каждое изменение покрыто (новые тесты или правка
   существующих), на нужном уровне — backend / frontend-unit / Playwright CT. Нет
   покрытия — добери. См. [`../test-policy/SKILL.md`](../test-policy/SKILL.md). Если
   правка трогает SRS/модель освоения — свери инварианты
   [`../srs-invariants/SKILL.md`](../srs-invariants/SKILL.md); Convex-функции —
   [`../convex-conventions/SKILL.md`](../convex-conventions/SKILL.md); контент —
   [`../content-authoring/SKILL.md`](../content-authoring/SKILL.md).
2. **Спека.** Создай/обнови `specs/<branch>.md` из полного диффа `main...HEAD` —
   скилл [`../spec/SKILL.md`](../spec/SKILL.md) (`/spec`). Pre-push гейт требует её
   для веток, тронувших `src/`/`convex/`.
3. **Code-review.** Прогони `/code-review` на диффе ветки, **провалидируй КАЖДУЮ
   находку** (реальная/ложная), реальные баги почини по TDD (красный тест,
   воспроизводящий баг → фикс → зелёно). Запомни итог для сводки (что нашло/починил).
4. **`npm run verify`** — typecheck + lint + unit + backend + Playwright CT.
   Зелёное.
5. **`npm run build`** — прод-сборка проходит.
6. **Браузер-смоук** — затронутое И смежное, [`../browser-smoke/SKILL.md`](../browser-smoke/SKILL.md);
   верифицируй сам через `preview_*`, не перекладывай на пользователя.

## Отгрузка (до PR включительно)

7. **Коммит(ы)** осмысленными порциями, сообщение по существу. Футер:
   ```
   Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>
   ```
8. **Push ветки.** `.githooks/pre-push` сам ещё раз прогонит spec-гейт + `npm run
   verify`. Блокирует — **почини причину**, не обходи `--no-verify` без явного
   решения пользователя.
9. **PR в `main`** — `gh pr create`. В теле: что и зачем, ключевые решения,
   тестирование, итог code-review. Футер тела:
   ```
   🤖 Generated with [Claude Code](https://claude.com/claude-code)
   ```
   НЕ мёржить самому — мёрж в `main` запускает прод-деплой + сид (CLAUDE.md → Деплой);
   это решение пользователя.

## Итоговая сводка пользователю

Коротко: что сделано, что code-review нашло и что починено (или «находок нет»),
ссылка на PR. Подтверди, что verify/build зелёные и смоук пройден — с доказательством,
без голословного «работает».
