# Тема «Неправильные глаголы» — спряжение в presente

Ветка: `feat/irregular-verbs-present` · дата: 2026-07-18 · статус: в работе (PR откроется из этой ветки)

## Цель

Первая грамматическая тема курса: спряжение восьми полностью неправильных
глаголов европейского португальского в настоящем времени. Запрос владельца:
«каждый глагол — отдельная часть темы, формы с местоимениями — слова части».
Вписана в обычную программу (вариант «контентная тема», выбран владельцем):
формы проходят через штатный цикл MC/Type/SRS/повторение/аудирование — для
зубрёжки парадигм интервальное повторение и нужно.

## Изменения данных / API

Только контент ([`convex/content.ts`](../../convex/content.ts)) — кода нет.

- Новая тема `irregular_present` «Неправильные глаголы» (🔀), в списке сразу
  после `verbs` (инфинитивы уже там — тема продолжает их формами).
- 8 уроков `irr_pres_{ser,estar,ter,ir,vir,dar,por,haver}`, «Часть N — Verbo
  (перевод)». В уроках 1–7 по 5 слов-форм: eu / tu / ele-ela-você / nós /
  eles-elas-vocês. Урок 8 — 3 слова: `há`, `não há`, `há muito tempo`.
- Теория каждого урока — «таблица» через секции «Единственное/Множественное
  число»; intro несёт узус (ser vs estar, «у меня есть» = ter, ir+инфинитив
  как будущее, pôr a mesa), tip — примеры-предложения.
- +22 предложения `TOPIC_SENTENCES` темы (дописаны в конец, append-only) для
  раздела «Построение предложений».
- Обновлён golden-снапшот пар `(lessonKey, pt)`: в диффе только добавления
  (+38 строк), существующие пары не тронуты.

## Поведение (для пользователя)

Новая тема в списке тем после «Глаголов»: 8 частей + строка «Построение
предложений». Формы учатся как обычные слова (выбор/ввод/аудио), попадают в
общее «Повторение» по SM-2. MC-дистракторы берутся из своего урока (штатный
`getWrong`) — варианты к «sou» это és/é/somos/são, т.е. упражнение само
превращается в тренировку спряжения. `note` каждой формы — мини-пример
употребления; он виден только в фидбэке после ответа и в теории (штатное
поведение, ответ не спойлерит).

## Ключевые решения и алгоритмы

- **Состав восьмёрки** (ser, estar, ter, ir, vir, dar, pôr + haver) — глаголы с
  полностью собственной парадигмой presente; канон грамматики EP. Следующий
  эшелон (fazer, dizer, saber, poder, ver, ler…) неправилен точечно (обычно
  1-е лицо) — это другой формат уроков, осознанно отложен (см. «Дальнейшие
  шаги»).
- **Без vós** — архаично для современного EP, учебники A1 его не дают: 5 форм
  на глагол.
- **haver ≠ полная парадигма.** В живом presente существует только `há`
  (hei/hás/havemos/hão мертвы вне книжного haver de) — часть 8 учит `há`,
  `não há`, `há muito tempo`, intro объясняет почему.
- **`pt` — голая форма без местоимения** («sou», не «eu sou»): иначе MC ru→pt
  решается подбором местоимения (eu=я), а не знанием формы; лицо указано в
  `ru` скобкой «(я) есть»; для 3-х лиц — «(он/она/você)» / «(они/vocês)»,
  консистентно с темой pronouns («você = вы к одному», «vocês = к нескольким»).
- **Инфинитивы не дублируются**: `ser`/`estar`/… как слова живут в теме
  `verbs` — глобальная уникальность `pt` не нарушена; все 38 новых `pt`
  свободны (проверено тестом-инвариантом).
- **Предложения — с явным субъектом** (Eu sou…, Ela tem…, O livro está…): без
  субъекта cloze-пропуск формы имел бы несколько грамматически верных ответов
  среди дистракторов-форм той же темы («___ em casa» — estou/estás/está…).
  Blank'и всех 22 предложений уникальны по норме (deaccent) — в частности,
  из пар tem/têm и vem/vêm blank'ом сделана ровно одна форма.
- **tem/têm, vem/vêm при вводе взаимно зачитываются** — проверка ответа
  курса accent-insensitive (`variantsMatch`/`deaccent`). Осознанно принято:
  различие тренируют MC, карточки теории и intro («различие только в ê»);
  менять общий нормалайзер ради пары форм — нет.

## Известные ограничения / дальнейшие шаги

- Ввод не различает tem/têm и vem/vêm (см. выше) — принято.
- Очередь развития грамматики (по согласованию с владельцем, после обкатки
  этой темы): (1) регулярное спряжение -ar/-er/-ir — тема должна встать в
  списке ДО неправильных; (2) второй эшелон «неправильные первые лица»
  (faço, digo, sei, posso…) + полные уроки ver/ler; (3) времена — отдельная
  тема на время (`irr_pps_*`); там ser и ir делят претерит (fui…) — один
  общий урок, а «vimos» (vir presente ∩ ver PPS) потребует осознанного
  ослабления инварианта «pt уникален глобально» (allowlist омографов;
  клиентский `wordTopicMap` к дублям уже готов).
