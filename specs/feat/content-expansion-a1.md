# feat/content-expansion-a1 — расширение курса до A1-объёма

- **Ветка:** `feat/content-expansion-a1`
- **Дата:** 2026-07-03
- **Статус:** готово к PR

## Цель

Закрыть дыры контента уровня A0–A1 (европейский португальский): в курсе не было
местоимений, вопросительных слов, частотных наречий (também/já/ainda), чисел
70–90 и mil, месяцев/сезонов, денег/покупок, продуктов/ресторана, людей вне
семьи (amigo!), стран/языков/работы, чувств и одежды. Слова euro и fome
использовались в кросс-предложениях, но нигде не преподавались. Один PR,
только контент (`content.ts`) — код не менялся (в `courseQueries.ts` лишь
обновлён устаревший комментарий с цифрами курса).

Итог: **13 → 20 тем, 23 → 41 урок, 255 → 431 слово, 25 → 55 предложений**.

## Code-review (10 углов + sweep) — что нашло и что починено

Лингвистика pt-PT (все починены): согласование «A conta **são** N euros»
(cs_0015 + новое предложение); «São três euros e cinquenta» вместо
неидиоматичного «Fica…»; «Saúde!» — только тост, на чих в Португалии говорят
**Santinho!** (note+tip); «Fixe» — общеразговорное, не «молодёжное»; «esse —
тот (у собеседника)», а не «(рядом)»; «saudade — тоска / ностальгия» (вместо
несловарного «скучание»); note «empregado de mesa»; intro притяжательных
переформулирован (скобки читались как род русских слов).

Семантические конфликты MC/Type (починены): telefone → «телефон
(стационарный)» рядом с telemóvel в одном уроке; multibanco → «банкомат»
(перевод «оплата картой» провоцировал выбор cartão); feriado → «выходной /
нерабочий день» (делил «праздник» с festa в одном уроке); relógio → «часы
(прибор)»; note «Está bem. ≠ Estou bem.» (аудио-омофоны).

Структура уроков (починено): +4 числа НЕ раздувают numbers_2 до 19 слов, а
живут отдельным `numbers_3` — порог готовности темы (≥80%) считается по теме
и одинаков в обоих вариантах, зато 19-словный урок давал бы «выучено 0 из 19»
~5 сессий подряд, и лейбл «Числа 11–100» врал бы про mil; «Que horas são?» —
в days_2 (вопрос рядом с ответом), isto — к указательным в pronouns_2;
dele+dela слиты в одну слэш-карточку (паттерн `dois / duas`); «o senhor /
a senhora» = «господин / госпожа» (было три неразличимых «вы» в одном
MC-пуле); gente убран (путался с pessoa числом в MC).

Отклонено осознанно: porquê/porque в Type-вводе схлопываются
деакцент-нормализацией (`normAnswer`) — это общий дизайн прощения диакритики
(«nao» ≙ «não»), ru-промпты различимы, MC/аудио не страдают; azeite/manteiga
делят слово «масло» с уточнениями — паттерн mão/braço, различие прилагательным
и есть предмет тренировки; массовая чистка notes-напоминалок — дублирование
теории в note является стилем курса с первых уроков; «лишние» ресторанные
предложения — у каждого уникальное required-слово.

## Сохранность прогресса

- Ни один существующий `lessonKey`/`pt` не переименован и не удалён: дифф
  golden-снапшота — **176 добавленных строк, 0 удалённых/изменённых**.
- Предложения — только append (sentenceKey из индекса не сдвинулся).
- Эффект для активных пользователей (осознанный компромисс, самозалечивается):
  % готовности пополненных тем (days_time, home, phrases + новые уроки в
  greetings/numbers/basics/verbs/family) временно просядет — у пользователя со
  100% по старым темам готовность упадёт до ~61–95% в зависимости от темы, и
  из-за гейта ≥80% **большинство уже открытых кросс-предложений (≈21 из 25)
  временно уйдёт из ротации** до подучивания новых уроков этих тем. Это цена
  любого пополнения тем; grandfathering потребовал бы кода и не делался.

## Ключевые решения

- **Один PR, не серия** — однородные append-only данные одного файла (решение
  владельца).
- Новый крупный вокаб — **новыми темами** (restaurant, а не food_3; calendar,
  а не days_3): не роняем готовность существующих тем больше необходимого.
- Малые дополнения десяток — **новым уроком numbers_3**, потому что порог
  готовности темы от разбивки не меняется, а урок-переросток и лживый лейбл —
  чистый минус (см. Code-review выше).
- «Апельсин» не добавлен: `pt: "laranja"` занят цветом, межурочные дубли
  запрещены инвариантом (жалоба №3 из PR #48).
- Европейские формы везде: telemóvel, ementa, empregado de mesa, cêntimo,
  talho, sapatilhas, camisola, bebé, multibanco, saldos, Santinho; месяцы,
  сезоны и языки со строчной, праздники с заглавной.
- 12 месяцев одним уроком (calendar_1) — чуть больше нормы «~10», но резать
  месяцы на два урока хуже дидактически (прецеденты: basics_1 = 16).

## Тестирование

Чисто-контентная правка: весь существующий набор инвариантов
(`convex/content.test.ts`) валидирует новые данные автоматически — required
существуют, слова ⊆ секции теории (в обе стороны), `answer === words.join(" ")`,
глобальная уникальность pt/lessonKey, tip без флага. Golden-снапшот обновлён
осознанно (`vitest -u`), дифф против main проверен: только добавления.
`npm run check` + все тесты (205) зелёные; сид на dev-деплой прогнан,
счётчики сходятся.
