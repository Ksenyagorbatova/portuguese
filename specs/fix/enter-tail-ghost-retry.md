# Хвост Enter'а с «Дальше» давал фантомный пустой ответ на карточке ввода

Ветка: `fix/enter-tail-ghost-retry` · 2026-06-11 · готово

## Баг (репорт владельца)

Ответив на любое упражнение и нажав Enter на «Дальше», пользователь попадал на
следующую карточку; если это карточка ввода — сразу выскакивал жёлтый
«Не совсем!», будто Enter уже нажат один раз с пустым полем.

## Причина

Обратная сторона фикса `fix/enter-skips-type-feedback` (#41): «Дальше»
активируется браузером на **keyDOWN** Enter → `advance()` → новая карточка
ввода монтируется с autoFocus-инпутом, пока клавиша ещё зажата. **KeyUP** того
же физического нажатия прилетает в свежий инпут, который теперь отвечает на
keyup → `check()` с пустым значением → ретрай-алерт на нетронутом слове
(и съеденная первая попытка). Adversarial-ревью #41 рассматривало эту гонку,
но только внутри одной карточки — переход «кнопка → новый инпут» просмотрели.

## Фикс

**Армирование пары down+up**: инпут засчитывает Enter только если ОБЕ половины
нажатия случились в нём самом. `onKeyDown(Enter)` взводит `enterArmedRef`;
`onKeyUp(Enter)` срабатывает только взведённым (и сбрасывает). Keyup без
своего keydown — хвост чужого нажатия — игнорируется. Ремаунт карточки
обнуляет ref естественно. Удержание/авторепит: повторные keydown'ы взводят
повторно (no-op), keyup один → один ответ; уход фокуса между down и up
оставляет взведённый ref, который умирает с карточкой — мусора нет.

## Тестирование (TDD)

Воспроизведение требует НАСТОЯЩЕЙ пары down/up через границу ремаунта —
сделан CT-харнесс [`src/test/EnterTailHarness.tsx`](../../src/test/EnterTailHarness.tsx)
(мини-модель Session: autoFocus-«Дальше» → по клику монтируется ввод;
компоненты в тест-файлах Playwright CT не поддерживает — прецедент `Boom.tsx`).
Тест: `keyboard.down("Enter")` (кнопка активируется, инпут в фокусе) →
`keyboard.up` → «Не совсем!» ОТСУТСТВУЕТ; затем полное нажатие → ретрай есть
(пустой Enter жив). **Красный без армирования — проверено отключением гарда**
(падал ровно на фантомном алерте); с фиксом весь набор зелёный
(`verify`: 168 unit/backend + 117 CT, build чист). Старые Enter-тесты #41
(проскок, авторепит, пустой, вторая попытка) не тронуты и зелёные.

Нюанс CT: root харнесса — сама кнопка, поэтому ассерты теста — `page.*`
(`component.getByRole` ищет только потомков root).
