# fix/user-reported-training-issues — три жалобы пользователей на тренировку

- **Ветка:** `fix/user-reported-training-issues`
- **Дата:** 2026-07-02
- **Статус:** готово к PR

## Цель

Закрыть три жалобы пользователей прода одним пакетом:

1. В сессии повторения каждая карточка показывала «следующий повтор: **прямо
   сейчас**» — бессмысленная строка.
2. Конструктор предложений всплывал в темах, к которым фразы не относятся
   («конструктор не к месту» + «фразы из ранних тем»).
3. В теме «Внешность» тренировались слова из «Частей тела» (`olho`, `cabelo`) —
   как «новые» и без показа в теории («вообще ещё не проходились»).

## Причины (диагноз)

1. Пре-ответная строка выводилась только для `tag === "due"`, а у due-слова
   `due` всегда в прошлом → `nextDueLabel` вырождался в константу «прямо сейчас»
   на каждой карточке повторения. Информации в строке не было ни при каком теге.
2. `eligibleSentences` гейтил только выученность `required` и ≥80% готовности их
   тем — без связи с текущим уроком: предложения первой освоенной темы вставлялись
   в сессию ЛЮБОГО урока.
3. Контент держал 16 дублей `pt` между уроками (у каждой пары `(lessonKey, pt)`
   свой прогресс — выученное в одной теме слово в другой снова «новое»), а часть
   слов урока не входила ни в одну секцию теории (`Theory.tsx` рендерит только
   пересечение `sections[].words × lesson.words` — слово «из ниоткуда»).

## Изменения данных

Вычищены **все 16 межурочных дублей**; канон — урок, где слово тематически дома
(и, при прочих равных, более ранний — сохраняет наибольший накопленный прогресс):

| убрано из | слова | канон |
|---|---|---|
| `basics_2` | grande, pequeno, novo, velho, caro, barato | `basics_1` («Качество») |
| `city_2` | aqui, ali | `basics_2` («Время и место») |
| `verbs_2` | querer | `verbs_1` (главные глаголы) |
| `colors_2` | olho, cabelo | `body_1` / `body_2` (жалоба №3) |
| `body_2` | farmácia | `city_1` («Места») |
| `home_2` | cadeira, sofá, televisão, jardim | `home_1` («Комнаты и мебель») |

Слова вне теории получили чипы/секции: `querer` → «Самые важные» (verbs_1),
`abrir` → «Бытовые» (verbs_2), `perna`+`cabelo` → «Ещё части тела» (body_2),
`dia`/`semana`/`fim de semana` → «Неделя» (days_1), `Quanto custa?`/`A conta,
por favor.`/`De onde é?` → «Покупки и знакомство» (phrases_1). Секция basics_2
«Размер и вид» стала «Вид» (bonito/feio), label урока — «Часть 2 — Вид, время,
место».

Прод вычищается автоматически prune-фазой `seedContent` при деплое; осиротевшие
`progress`-строки дублей безвредны by design (их никто не читает). Прогресс
канонических пар не затронут. `required` кросс-предложений не менялись — все
ссылаются на выжившие `pt`; гейт cs_0014 («Ela tem olhos azuis…») теперь ждёт
готовности темы «Тело и здоровье», что семантически правильнее.

## Поведение (для пользователя)

- Карточка упражнения больше НЕ показывает строку «следующий повтор …» до
  ответа; честное расписание после ответа осталось в `Feedback`.
- В сессии урока конструктор предложений приходит только с фразами темы этого
  урока (хотя бы одно `required`-слово из неё). В глобальном повторении — как
  раньше, любые открытые предложения.
- Слова больше не дублируются между темами: «Внешность» — только прилагательные
  внешности; каждое слово урока видно в теории до тренировки.

## Ключевые решения

- **Строку убрали целиком**, а не спрятали для повторения: для не-due слов её
  прятали и раньше как шум, для due она константна → ни одной ветки, где она
  информативна.
- **Фильтр по теме — третий пункт гейта (в)** внутри `eligibleSentences`
  (опциональный `forTopicKey`), а не отдельная функция: сохраняет единый гейт и
  позволяет `buildReviewQueue` работать без фильтра. `wordTopicMap` остаётся
  `Map<pt, Set<topicKey>>` — защита на случай возвращения дублей.
- **Дубли решены удалением, не миграцией**: prune-фаза сида уже умеет вычищать
  контентные строки; переносов слов между уроками нет (перенос = переименование
  ключа = осиротение канонического прогресса).
- Golden-снапшот пар `(lessonKey, pt)` обновлён **осознанно**: в диффе ровно 16
  удалённых пар, ноль переименований/изменений.

## Тестирование

- `convex/content.test.ts` — два новых инварианта (оба до фикса красные):
  `pt` уникален глобально; каждое слово урока показано хотя бы в одной секции
  теории. Снапшот пар обновлён.
- `src/lib/queue.test.ts` — новый блок «тематический фильтр предложений»:
  чужая тема — не вставляется (красный до фикса, воспроизводит жалобу №2);
  своя тема — вставляется; предложение из слов двух тем — в уроках обеих;
  `buildReviewQueue` не фильтрует. Старый тест ANY-topic-гейта дублей оставлен
  как защита от их возвращения.
- CT: `McExercise.ct.tsx` / `TypeExercise.ct.tsx` — тест «due-слово показывает
  строку» перевёрнут в «НЕ показывает» (плюс прежний «не-due не показывает»).
- Полный прогон: `npm run verify` + `npm run build` зелёные; браузерный смоук
  по затронутым потокам (сессия урока, повторение, теория «Внешности»).

## Известные ограничения / дальнейшие шаги

- Пользователи, доучившие дубль (например, `grande` в `basics_2`), теряют
  прогресс именно дубля; канон (`basics_1`) не затронут. Осознанный компромисс —
  дальше слово живёт в одном месте.
- CSS-правила `.m-q-srs` в `src/index.css` оставлены (вербатим-CSS проекта не
  чистим); класс больше нигде не рендерится.
- Кросс-предложения по-прежнему глобальный пул: если у темы нет своих фраз,
  конструктор в её уроках не появится вовсе — при желании можно дописать
  тематические предложения (append-only) отдельной контентной задачей.
