# Спойлер-заметка, focus-visible, контраст (дизайн-ревью v2, блок B)

Ветка: `fix/a11y-spoiler-contrast` · 2026-06-10 · готово (PR 2/3 серии
дизайн-ревью v2; блок A — `feat/session-static-queue`, блок C — далее)

## Цель

Блок «обучение и доступность» (#4–6) из дизайн-ревью v2
(handoff-пакет `design_handoff_review_v2`). Чисто фронт, серверных изменений нет.

1. **#4** 💡-заметка под вопросом показывалась ДО ответа и спойлерила его
   (заметка часто пересказывает перевод) — убрать из упражнений; после ответа
   и в теории заметка остаётся.
2. **#5** Единый язык клавиатурного фокуса: кольцо `--accent-ring` (как у
   инпутов) на всех интерактивах — только `:focus-visible`.
3. **#6** Контраст WCAG AA: текст кеглем ≤13px не светлее `--ink-500`
   (`--ink-400` ≈ 3.4:1 на белом — только с 14px).

## Поведение

- Во время вопроса (MC и Type) 💡-заметки нет; после ответа она в фидбэке
  (`WordFeedback` — не менялся), в теории — на обороте флип-карты (не менялась).
  Служебные хинты («Акценты и пунктуация необязательны…», «Нажми на
  карточку…») остались как были. Опциональное гашение хинтов после 2–3
  показов — отложено (низкий приоритет, по согласованию).
- Tab по экрану — на каждом интерактиве видно кольцо `0 0 0 4px
  var(--accent-ring)`; у элементов с собственной тенью (`--e-accent`: primary
  кнопка, плитка ответа, логотип; `--e1`: ghost-кнопка, вариант ответа, плитка
  банка, крестик выхода, икон-кнопки хедера) кольцо добавляется К тени. При
  клике мышью кольца нет.
- Цвета мелкого текста: `--ink-400 → --ink-500` в `m-stat-l` (11px),
  `m-ring-cap` (10px), `m-lesson-meta` (12px), `m-q-srs` (12.5px), `m-hint`
  (12.5px), `m-flip-cue` (11px), `m-signin-kicker` (12px) + `m-opt-key` (13px,
  в списке спеки хендоффа не было — покрыт правилом «минимум в»). Размеры не
  менялись. Тёмная тема использует те же селекторы — там свой маппинг токенов.

## Ключевые решения

- **Расхождения спеки хендоффа с кодом** (спека писалась по прототипу):
  `m-hero-cap` и `m-progress-count` уже были `--ink-500`; `m-ans-ph` — вообще
  `--accent` (не трогал). `.m-switch b` в focus-списке — невидимый сейчас div
  без `tabIndex` (регистрация отключена) — фокус на него не попадает, опущен.
- В focus-список добавлены `m-seg-btn` (существует — кнопки сегмент-контрола)
  и `m-mist-audio` (кнопка озвучки разбора ошибок из блока A — класс появится
  после мёржа PR блока A; до того селектор просто не матчится).
- Кольцо реализовано «слоями»: базовый `:where(...)` с нулевой специфичностью
  + два override-правила для теневых элементов (`--e-accent`, `--e1`) — тень
  сохраняется под кольцом.
- Правила `.m-q-note` / `.m-session .m-q-note` удалены — после #4 класс нигде
  не рендерится (в фидбэке свой `m-fb-sub`, в теории — `m-flip-note`).

## Известные ограничения

- `autoFocus` на «Дальше»: видимость кольца после ответа зависит от modality
  последнего ввода (клавиатура → кольцо; мышь → браузерная эвристика
  :focus-visible может кольцо не рисовать — это согласуется с «при клике мышью
  кольца нет» из той же спеки).
- Гашение служебных хинтов через localStorage — осознанно отложено.
