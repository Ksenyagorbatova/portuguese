# Enter «проскакивал» фидбэк в карточке ввода (+чип-подсказка ↵)

Ветка: `fix/enter-skips-type-feedback` · 2026-06-11 · готово

## Цель

Баг-репорт владельца: в упражнении ввода ответ Enter'ом (верный, неверный со
второй попытки — любой, дающий вердикт) не показывал карточку фидбэка — сразу
перелистывало на следующее слово. Мышкой по «Проверить» — всё в порядке.

## Причина

Ответ обрабатывался на **keydown** Enter: `check()` → `resolved` → React
синхронно рендерит фидбэк и autoFocus-«Дальше» — фокус уезжает на кнопку ещё
ДО того, как пользователь отпустил клавишу. Chrome добивает то же физическое
нажатие **кликом по свежесфокусированной кнопке на keyup** → `onNext()` —
фидбэк жил миллисекунды. Старый `e.repeat`-гард защищал только от автоповтора
удержания, а не от пары down/up одного нажатия. В MC бага нет: хоткеи — цифры
и буквы, keyup которых кнопку не активирует.

## Фикс

Ответ перенесён на **keyUP** ([`TypeExercise.tsx`](../../src/components/exercises/TypeExercise.tsx)):
к моменту срабатывания фокус ещё в инпуте, нажатие потрачено целиком; фокус
уезжает на «Дальше» уже ПОСЛЕ отпускания. Следующий Enter — отдельное полное
нажатие, его keydown честно активирует «Дальше» — поведение «Enter ведёт
дальше» сохранено. `e.repeat`-гард стал не нужен (авторепит шлёт только
keydown'ы); guard от двойного ответа (`pendingRef`) не тронут.

## Заодно: discoverability хоткея

На кнопке «Проверить» — чип `↵` (класс `m-btn-key`, язык чипов A–E из выбора:
полупрозрачный белый поверх primary). `aria-hidden` — имя кнопки остаётся
«Проверить»; на таче скрыт тем же `pointer:coarse`-правилом, что `m-opt-key`.

## Тестирование

TDD: три воспроизводящих CT-теста (Playwright, настоящие down/up) — красные до
фикса (2 из 3; «пустой Enter» и раньше не проскакивал — даёт ретрай без
кнопки), зелёные после:
- верный ответ Enter'ом → «Верно!» виден и через 400мс, `onNext` не вызван;
- пустой Enter → «Не совсем!», ни ответа, ни перехода;
- неверный со 2-й попытки Enter'ом → «Правильно:…» виден, `onNext` не вызван.

Существующий тест «удержание Enter (авторепит) — один ответ, одна мутация»
остался зелёным без правок (его прямые keydown-диспатчи теперь игнорируются по
определению — отвечает только keyup).

## Известные ограничения

- Ответ срабатывает на отпускании клавиши — при удержании Enter задержка равна
  длительности удержания (обычно <150мс, незаметно).
