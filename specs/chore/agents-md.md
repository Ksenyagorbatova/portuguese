# AGENTS.md для не-Claude агентов

Ветка: `chore/agents-md` · PR: (TBD) · 2026-06-09 · Статус: готово к ревью

## Цель

Добавить корневой `AGENTS.md` — точку входа для ИИ-агентов, которые ищут именно
`AGENTS.md` (Codex, Cursor и т.п.), а не `CLAUDE.md`. Тонкий, без дублирования всей
архитектуры: несокращаемые правила inline + ссылки на `CLAUDE.md` и `specs/`.

## Изменения данных / API

Нет. Только документация (`src/`/`convex/` не тронуты).

## Поведение

`AGENTS.md` даёт агенту, читающему только его, рабочий минимум: метод context7,
ветка→PR, тесты, спека на задачу, code-review gate, «всё зелёное перед push», и
короткий список команд. За полным гайдом — отсылка к `CLAUDE.md` (источник правды)
и `specs/` (подсистемы).

## Ключевые решения и алгоритмы

- **Тонкий файл, не зеркало CLAUDE.md.** Полное дублирование разъезжается со
  временем; здесь — только несокращаемые правила + указатели. `CLAUDE.md` остаётся
  единственным источником правды, чтобы не поддерживать две копии архитектуры.
- Правила сформулированы самодостаточно (агент, не открывший `CLAUDE.md`, всё равно
  не нарушит workflow: ветка/PR, тесты, спека, code-review, verify).

## Тестирование

Кода нет — автотесты не добавляются. Проверка: `npm run verify` зелёный (документная
правка ничего не ломает); ссылки в `AGENTS.md` ведут на существующие файлы.

## Карта файлов

Добавлено: `AGENTS.md`, `specs/chore/agents-md.md`.

## Известные ограничения

- `AGENTS.md` намеренно не повторяет архитектуру — при крупных изменениях процесса
  держать его несокращаемые правила в синхроне с `CLAUDE.md` (правил мало, дрейф
  маловероятен).
